# PerGon — Art Direction

> Dirección de arte oficial.  
> Define **cómo se ve y se siente** PerGon en cualquier soporte.  
> Complementa `BRAND_SYSTEM.md`. En conflicto de producto UI, prevalecen `UI_UX_PRINCIPLES.md` + rules de superficie.

---

## 1. Norte creativo

**Una frase:** precisión industrial + confianza tecnológica, con calma.

Referencias de **calidad** (no de copia visual): claridad tipo Apple, densidad útil tipo Linear, solemnidad de sistemas de confianza, craft de producto tipo Stripe/Vercel.  
PerGon **no** imita ninguna marca.

### 1.1 Moodboard verbal

- Acero cepillado, vidrio técnico, papel de archivo, luz de taller controlada.
- Pantallas limpieas, tipografía dominante, cero teatro.
- Producto físico siempre anclado a identidad digital (pasaporte/QR).

### 1.2 Anti-mood

- Laboratorio stock con humo y tubos de ensayo genéricos.
- “Clean beauty” crema/terracotta.
- Dashboard SaaS con purple glow.
- Landing de detergente con burbujas y sonrisas.

---

## 2. Principios de dirección

1. **Una composición por beat.** Un mensaje, un ancla visual.
2. **Materiales reales > abstracción moda.**
3. **Negativo deliberado.** El aire es estructura.
4. **Escala tipográfica como protagonista** en Web.
5. **Color como semántica**, no como decoración.
6. **Artefactos de dominio con dignidad** (pasaporte, QR).
7. **Motion con propósito** (máx. 2–3 intenciones fuertes por escena Web).
8. **Admin sin cine.** Operación, no storytelling.

---

## 3. Composición

### 3.1 Web / producto

- Primer viewport: marca + un headline + una frase + CTA group + plano visual dominante edge-to-edge.
- Sin cards en hero; sin badges flotantes; sin stats inventados.
- Capítulos: ritmo vertical generoso; fondos canvas/panel alternados con disciplina.
- Rejilla sutil (`stage`) permitida como atmósfera técnica, no como wallpaper ruidoso.

### 3.2 Verify

- Solemnidad: tipografía grande de dictamen, metadata mono, poco color.
- Sensación de documento institucional, no de app de consumo.

### 3.3 Expert

- Escritorio de especialista: contexto + consulta + dictamen.
- Prohibido chat bubble, orbes, avatares robot.

### 3.4 Admin

- Densidad alta, chrome estable, tablas y filtros primero.
- Prohibido glass, hero marketing, KPI theater vacío.

---

## 4. Luz y atmósfera (cross-media)

| Contexto           | Luz                                                       | Atmósfera               |
| ------------------ | --------------------------------------------------------- | ----------------------- |
| Producto / hero    | Soft key + fill controlado; highlight especular contenido | Limpio, frío-neutro     |
| Verify / pasaporte | Luz plana, alto contraste tipográfico                     | Archivo / certificación |
| 3D                 | Studio HDRI técnico; ver `3D_GUIDE.md`                    | Material honesty        |
| Admin              | Sin atmósfera fotográfica                                 | UI pura                 |

---

## 5. Jerarquía visual (orden de lectura)

1. Marca o dictamen
2. Mensaje primario
3. Ancla visual (producto / pasaporte / QR / escena)
4. Soporte
5. Metadata

Si todo grita, la dirección falló.

---

## 6. Textura y material

Permitido: metal técnico, polímero mate, etiqueta papel/synthetic, tinta nítida, vidrio, líquido solo si el producto lo exige y no se vuelve “química stock”.  
Prohibido: glitter, bokeh excesivo, dust overlays, lens flare de moda.

---

## 7. Motion art direction

- Entradas: opacity + translateY corto; easing `ease-out` de sistema.
- Scroll: un concepto por beat; sin scrolljacking.
- Verify: sin pulse infinito.
- 3D: loop suave o idle de presencia; nunca competir con blur animado.

Detalle: `05-animations` rules + `3D_GUIDE.md`.

---

## 8. Dirección por canal

| Canal              | Prioridad                                        |
| ------------------ | ------------------------------------------------ |
| Web                | Narrativa + confianza                            |
| Admin              | Productividad                                    |
| Redes              | Un claim + un artefacto; crop tipográfico fuerte |
| Packaging          | Legibilidad + QR + pasaporte                     |
| Stands / vehículos | Wordmark + isotipo a distancia; alto contraste   |
| Presentaciones     | Tipografía > fotografía; pocas slides densas     |

---

## 9. Anti-patrones de dirección (lista negra)

- Plantilla Hero → Features → Testimonials.
- Feature grids con iconos emoji.
- Glassmorphism global.
- Gradientes mesh / purple AI.
- Collage de frascos sin sistema.
- Stickers “New / AI / Secure” flotantes.
- Cards anidadas por costumbre.
- Parallax agresivo y bounce en UI crítica.

---

## 10. Checklist de art direction

- [ ] ¿Parece PerGon o un template?
- [ ] ¿Una intención primaria clara?
- [ ] ¿Ancla visual real (producto/sistema), no stock vacío?
- [ ] ¿Tipografía lidera?
- [ ] ¿Color contenido?
- [ ] ¿Motion justificado?
- [ ] ¿Superficie correcta (Web vs Admin vs Verify)?
